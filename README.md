# classification_bonded_knots

This repository contains the code and data used for the classification of **uncolored bonded knots**.

Bonded knots provide a topological model for knotted graphs with additional bonds, motivated in part by applications to biomolecular structures such as proteins with intramolecular bridges. In this work, we focus on the **uncolored** case and classify bonded knots of small complexity.

The computations and diagram manipulations are implemented using the [`knotpy`](https://github.com/bgabrovsek/knotpy) library.
